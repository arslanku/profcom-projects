# profcom-projects

Шаблон репозитория для управления задачами команды из 10–15 человек с помощью GitHub Issues и GitHub Projects. Задачи хранятся в Issues, а Project даёт команде общий обзор работы.

## Начало работы

1. Добавьте участников команды в репозиторий или организацию, выдавая необходимые права.
2. Создайте GitHub Project и добавьте в него Issues этого репозитория.
3. Используйте поля **Status**, **Priority** и **Assignees**. Для Status подойдут значения: `Бэклог`, `К выполнению`, `В работе`, `На проверке`, `Завершено`. Для Priority используйте уровни `P0`–`P3`.
4. Создайте представление-доску, сгруппированное по Status, и табличное представление открытых задач для планирования.
5. Добавляйте поле итерации только если команда планирует работу регулярными циклами.

## Работа с задачами

- Создавайте отдельный Issue на каждую понятную задачу. Шаблон **Задача** поможет описать ожидаемый результат, критерии приёмки, приоритет и ссылки.
- Назначайте одного ответственного за задачу; при необходимости он может привлекать других участников.
- Перемещайте задачу по статусам по мере выполнения. Закрывайте Issue, когда критерии приёмки выполнены.
- Регулярно просматривайте Project всей командой: уточняйте приоритеты, назначайте ответственных и обновляйте статусы. Если работа заблокирована, сообщите об этом в Issue и обозначьте, что нужно для продолжения.
